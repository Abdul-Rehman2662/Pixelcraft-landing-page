# Landing Page Concept 02 — Dark Digital Studio

A fictional portfolio landing page built with HTML, CSS, and JavaScript. It uses a dark editorial style, lime accents, abstract CSS artwork, and responsive project cards.

## Features
- Responsive desktop, tablet, and mobile layout
- Mobile navigation menu
- CSS-built logo and abstract artwork
- Animated hero orb and scrolling capability ticker
- Services, project concepts, about, and contact sections
- Reduced-motion accessibility support

## Run
Extract the ZIP and open `index.html` in a browser. No build tools are needed.

This is a fictional design concept, not a real business. Replace `hello@example.com` before using it for a real client.
